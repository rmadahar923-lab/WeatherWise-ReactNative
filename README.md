**Course:** SODV2205-02

**Team Members:**
- Ramandeep Kaur
- Navdeep Singh

## Project Overview
WeatherWise is a React Native weather application that will allow users to search for cities, check current weather, and view upcoming forecasts using the Open-Meteo API.

## Planned Screens
1. Home/Search – Search for a city and view current weather.
2. Forecast List – View upcoming weather forecasts.
3. Weather Details – View temperature, humidity, wind speed, and rain probability.

## Technologies
React Native, Expo, Axios, React Hooks, React Navigation, FlatList, Flexbox, and Expo Vector Icons.

1. Run `npm install`.
